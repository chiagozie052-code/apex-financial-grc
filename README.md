# Apex Financial Services — GRC & IAM Governance Portfolio

> **Simulated portfolio.** Every company, employee, system, record and result in this repository is fictional. No real employer, customer or employee information is used.

Hands-on governance, risk and compliance (GRC) work built around one fictional company, **Apex Financial Services**, a 500-employee financial services firm running Azure, Microsoft Entra ID, Microsoft 365, ServiceNow, Workday and Salesforce.

Each project follows the same chain: **Risk → Control → Evidence → Test → Finding → Remediation → Reporting**

## Highlights
- **Risk assessment:** 15 risks scored on likelihood × impact (9 High, 6 Medium) with treatment plans and owners, linked to a NIST CSF 2.0 gap analysis.
- **Control testing:** formula-driven pass/fail tests across access, change, patching and backup controls, with every exception reconciled to the test results.
- **Audit finding AF-001:** terminated users kept access 3 to 15 days after leaving; one account signed in after termination. Includes cause, risk, recommendation, management response and remediation dates.
