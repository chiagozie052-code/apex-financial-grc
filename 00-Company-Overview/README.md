# Company Overview — Apex Financial Services

Apex Financial Services is a fictional company created to serve as the 
consistent environment for this GRC/IAM portfolio. Every project in this 
repository — risk assessments, control testing, IAM governance, and AI 
governance — is built against this same simulated organization so the 
work reads as one coherent program rather than disconnected exercises.

## About This Portfolio

This repository demonstrates hands-on GRC and IAM governance skills through simulated work against a fictional financial services organization. Frameworks referenced include NIST CSF 2.0, SOC 2, ISO/IEC 27001, and the NIST AI Risk Management Framework.

**All data in this repository is fictional.** No real company, employee, customer, or system information is used anywhere in this portfolio.
